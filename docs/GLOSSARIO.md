# Glossário

| Termo | Significado no nosso produto |
| --- | --- |
| Tenant | Um cliente do white-label (marca, configuração e ambiente próprios) |
| Host / streamer | Quem transmite a live |
| Espectador | Quem assiste |
| Convidado / palestrante | Quem sobe ao palco de uma live (individual / em grupo) |
| Moedas | Moeda comprada pelo usuário e gasta no app |
| Diamantes | Ganhos do streamer, gerados por presentes e cobranças; base do saque |
| Presente | Item animado comprado com moedas e enviado a alguém |
| Super presente | Presente cujo envio é anunciado em todas as lives |
| Presente da sorte | Presente com retorno variável ao remetente (flag com trava jurídica) |
| Combo | Envio repetido do mesmo presente em sequência |
| PK | Batalha entre lives, vencida por quem recebe mais pontos em presentes |
| Live privada paga | Live cobrada por minuto de quem assiste |
| Sussurro | Presença discreta: só o host vê as mensagens e presentes do usuário |
| Incógnito | Aparece como anônimo na live |
| VIP | Assinatura com níveis e privilégios |
| Intocável | Privilégio VIP de não ser silenciado/expulso pelo host (não vale para a moderação da plataforma) |
| Bolsa de itens | Inventário de itens comprados ou recebidos |
| Família | Grupo de usuários com líder, gerentes, chat e ranking |
| Agência | Organização que agrega streamers e recebe comissão |
| Revendedor | Conta autorizada a transferir moedas para outros usuários |
| Ledger | Livro-razão de dupla entrada onde todo movimento de valor é registrado |
| Idempotência | Repetir a mesma operação não gera efeito duplicado |
| Flag | Chave que liga/desliga uma funcionalidade sem nova versão do app |
| mock-server | Servidor fake local que segue o contrato da API |
| Evento | Mensagem empurrada pelo servidor pelo WebSocket |
| Definição de pronto | Lista do que um item precisa cumprir para ser marcado como pronto |
